# Межрасовый баланс: контрольный прогон

Продолжение с постепенным составом и заменой одного стека: [исследование замен](balance-lab-swap-report.md). Оно точнее показывает, какой тип даёт прирост на каждом тире.

Проверка 22 октября 2026 года. Это **ИИ против ИИ**, а не прогноз результатов игроков. Для каждой пары проведено 600 боёв: по 200 при бюджете найма 300, 600 и 900 монет. Половина боёв в каждой группе меняет стороны местами. Используется реальный `Battle`, `BattleRules`, `BattleAi` и сгенерированное поле; начальные армии состоят из пяти стеков каждой фракции. Исходный seed фиксирован.

| Пара | Победы первого при 300 / 600 / 900 | Средняя доля побед |
| --- | --- | --- |
| Флора — люди | 80,5% / 68,5% / 72% | **73,7%** |
| Флора — нежить | 72% / 62% / 62% | **65,3%** |
| Люди — нежить | 39% / 39,5% / 44,5% | **41%** |

Источник: [`balance-lab-generated.json`](balance-lab-generated.json). В последней паре есть одна ничья из 600 боёв. Вывод для следующей настройки: флора явно сильнее при равном бюджете; нежить тоже несколько сильнее людей. Утверждённые пользователем характеристики пока сохранены, чтобы не менять их по одному тестовому сценарию.

Проверка причин: при отключении подчинения гриба доля побед флоры на сгенерированном поле снижается до 73% / 63% / 57% против людей и до 61% / 52,5% / 50,5% против нежити ([результат](balance-lab-generated-no-convert.json)). Механика подчинения влияет сильно, но не объясняет весь перевес. Эксперимент с удорожанием флоры на 10% дал 61,5% / 49,5% / 42,5% против людей и 40% / 41,5% / 40% против нежити ([результат](balance-lab-generated-flora-cost-1.10.json)); это слишком грубая настройка для всей фракции сразу. Эти варианты изменяли только симулятор, игровые цены не затронуты.

Важные ограничения: в тесте все пять типов доступны с начала, а в кампании найм открывается постепенно. Не учтены навыки героя, артефакты, ограничения ресурсов и особая карта горной заставы. Армии собираются случайно в пределах равного бюджета, а ИИ не отражает тактику игрока. Разброс от seed и состава армии достаточно велик; по этим цифрам нельзя назначить окончательную цену или урон. Следующий полезный тест — заданные типовые составы и бои с прохождением кампании.

Воспроизведение из корня репозитория:

```powershell
dotnet run --project tools/BalanceLab/BalanceLab.csproj -- . 100 generated
dotnet run --project tools/BalanceLab/BalanceLab.csproj -- . 100 generated no-convert
dotnet run --project tools/BalanceLab/BalanceLab.csproj -- . 100 generated flora-cost=1.10
```

Каждый вызов записывает JSON в `docs/`. Дополнительно проверялись ровное поле, отключённое лечение и более высокие цены, но они не использовались как основание для изменений характеристик. ИИ лекаря обновлён: он тратит действие только если союзнику недостаёт хотя бы 7 HP; лечение урона в 1 HP искажало контрольный эксперимент.

Проверка проекта: 537 тестов прошли, 5 проверок `CampaignBalanceTests.MandatoryCampaignCanBeWonWithStartingGoldAndNoOptionalBattles` остаются красными из-за ранее усиленных обязательных встреч первой кампании. Их следует разбирать отдельно с учётом фактического маршрута и экономики кампании.
