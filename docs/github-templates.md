# Формы задач на GitHub

После добавления этих файлов в основную ветку GitHub покажет формы при создании issue:

- **Сообщить об ошибке** попросит указать фактическое и ожидаемое поведение, шаги повтора и необязательный скриншот/лог.
- **Предложить игровую функцию** попросит описать проблему игрока, предложение и проверяемые критерии готовности.

Свободное issue остаётся включено для вопросов и задач, которым эти формы не подходят. При создании Pull Request GitHub автоматически подставит `.github/pull_request_template.md`: он напоминает запустить сборку и тесты, связать изменение с issue и приложить скриншоты после изменения экрана игры.

Формы используют стандартный YAML-синтаксис GitHub. В публичной репозитории поля с пометкой `required: true` нельзя оставить пустыми при отправке. Ответы GitHub преобразует в обычный Markdown-текст issue, поэтому позже их можно редактировать как привычное описание задачи.
