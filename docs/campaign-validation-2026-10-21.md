# Проверка первой кампании и эксперимент с картой

## Согласованное правило

Северный лес необязателен. Автор подтвердил 21 октября, что можно пройти горную засаду, защитить грибной аванпост и закончить кампанию без северной ветки. Север по-прежнему требует победы в выбранном бою крестьянского задания и открывает найм T2; этот бонус можно пропустить.

## Сквозные маршруты

`CampaignBalanceTests` проверяет пять прохождений: помощь/отказ с севером, помощь/отказ без севера и короткий маршрут без крестьян и севера. Проверяются оба слоя маршрута: прежний граф и настоящие `AdventureSurface`/`AdventureTravel`, включая подход к точке, подтверждение хода и радиус взаимодействия. Между этапами прогресс записывается через `CampaignSerializer` во временный файл, загружается и восстанавливается в новую кампанию. Пользовательский сейв не используется.

Стартовый найм: 18 кабачков и 8 ипомей за всё начальное золото. После северного боя при посещении этой ветки нанимается по одному бойцу T2; после защиты аванпоста — три гриба. Бои разыгрываются настоящими правилами и детерминированным ИИ за обе стороны, включая лечение. Побочные бои и артефакты не нужны для проверяемых маршрутов. Это подтверждает существование выигрышного прохождения, а не лёгкость для любого набора решений игрока.

Экранные переходы отдельно проверяются в `ExplorationFlowTests` и `CampaignScreenFlowTests`. Ручная проверка управления и субъективной сложности остаётся необходимой.

## Варианты карты

[Открыть сравнение трёх реальных игровых кадров](art/map-pixel-experiment.html).

В игре уже используется `PointClamp`. Дополнительного линейного сглаживания при выводе нет; мягкая светотень содержится в самом изображении фона. Эксперимент добавляет только параметр запуска:

```powershell
dotnet run --project src/Game.MonoGame/Game.MonoGame.csproj -- --map-pixels 1
dotnet run --project src/Game.MonoGame/Game.MonoGame.csproj -- --map-pixels 2
```

Без параметра остаётся исходник. Обработка выполняется один раз при загрузке, затрагивает только четыре текстуры острова и не меняет спрайты, HUD, исходные файлы или данные карты.

Независимое визуальное ревью: 1 px отличается мало, 2 px теряет мелкие детали и может выглядеть грубее персонажей. Второй эксперимент с лёгкой резкостью и блоком 2 × 2 тоже почти незаметен в игровом масштабе. Сам по себе фильтр не устраняет разницу между живописной светотенью фона и чёткими контурами юнитов. Поэтому ни один вариант пока не становится стандартным; доработка графики отслеживается в #22.

## Продолжение после обрыва чата

### Новое сравнение на выбранной старой карте

Пользователь предпочёл старую карту. [Сравнение новых эффектов](art/map-detail-experiment.html) показывает исходник, усиление контуров и усреднение до одного игрового пикселя с усилением контуров. Полная палитра сохранена. Новые эффекты работают по собранной карте, затем результат возвращается в четыре тайла, чтобы внутренние стыки не обрабатывались как внешние края изображения. Цветовые каналы ограничены прозрачностью для корректного premultiplied alpha; исправлено такое же ограничение в прежнем фильтре палитры.

Запуск экспериментов:

```powershell
dotnet run --project src/Game.MonoGame/Game.MonoGame.csproj -- --map-detail sharpen
dotnet run --project src/Game.MonoGame/Game.MonoGame.csproj -- --map-detail pixel
```

Ни один эффект не выбран по умолчанию. Независимое визуальное ревью: sharpen немного усиливает чёткость травы и деревьев, одновременно делая фактуру жёстче; pixel даёт небольшой выигрыш и местами укрупняет листву. Ни один вариант не приводит фон к пиксельному характеру юнитов. Если это по-прежнему не устраивает, следующий художественный шаг — переработка силуэтов и светотени исходных объектов в согласованном стиле, а не дальнейшее усиление фильтра.

После исправлений повторный полный запуск: **532 теста прошли, 0 ошибок, 0 пропусков**. Добавлены проверки влияния на контуры, плоские цвета, прозрачность, стыки тайлов и параметры запуска. Ревью исправлений не выявило оставшихся существенных проблем. Четыре кадра новых эффектов получены из обновлённой сборки. JavaScript страниц и локальные ссылки проверены; взаимодействие в браузере по-прежнему не проверено из-за ранее описанного запрета file-URL.

Первую кампанию нельзя считать полностью проверенной вручную: автоматические пять маршрутов и экранные тесты проходят, но ручная оценка управления и сложности остаётся открытой. Ко второй кампании в этом эксперименте не переходили.

Повторный полный запуск 21 октября: **532 теста прошли, 0 ошибок, 0 пропусков**. Release-сборка отдельного предпросмотра завершилась без ошибок и предупреждений. Это автоматическая проверка; субъективная сложность и ручное прохождение пока не подтверждены.

[Сравнение текущей карты и новой картинки пользователя](art/map-image-comparison.html) содержит четыре реальных кадра: игровой масштаб и обзор острова для каждого фона. В обоих вариантах одинаковые камера, состояние после выбора, героиня, отряд и интерфейс. Страница позволяет переключать карты целиком и сравнивать их ползунком. Независимый визуальный просмотр подтвердил сохранение композиции, но отметил, что новая карта в игровом масштабе мягче текущей и сильнее расходится по резкости с пиксельными юнитами. Она спокойнее выглядит в обзоре; замена текущего фона пока не признана улучшением.

Пользовательский PNG сохранён без изменений как `art/map-comparison-source.png` (5120 × 2304). Для примерки он разделяется на четыре равных тайла в отдельной сборке; игра сама масштабирует их в прежние координаты острова. Исходные игровые PNG не заменены. Предпросмотр не использует пользовательский сейв. Скрипт восстанавливает тайлы сборки в `finally` после захвата.

Визуально новая версия уменьшает пестроту травы и цветных мелких деталей, но живописная мягкость остаётся. По статическим кадрам поле и дороги расположены близко к текущему варианту; это не доказывает точное совпадение всех границ проходимости. Ни один вариант автоматически не выбран окончательным.

Размер новой картинки 5120 × 2304, у текущего мастера 7448 × 3380. При примерке новая картинка немного растягивается по вертикали под существующий мир (менее 1% отличия пропорций); координаты навигации, препятствий и точек интереса остаются теми же. Для точной проверки наложения всех дорог нужен отдельный просмотр в игре.

Воспроизведение (предварительно собрать игру в отдельный каталог):

```powershell

./docs/art/capture-map-comparison.ps1 -PreviewDirectory C:/Users/Vasya/Desktop/kursach/.map-comparison-build/bin/Game.MonoGame/release
```
