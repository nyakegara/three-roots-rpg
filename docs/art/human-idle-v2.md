# Idle людей v2

Встроенный ImageGen использовал текущий статический спрайт каждого юнита как визуальный reference. Прежние атласы и исходники сохранены. Новые исходники: `docs/art/animations/sources/human-{militia,banner-knight,inquisitor}.idle.v2.source.png`; игровые листы: `content/art/animations/unit.human.{id}.idle.v2.png`.

Рыцарь теперь сохраняет красный плюмаж, светлые латы и щит с лилией; крестьянин держит вилы; инквизитор сохраняет длинные волосы, тяжёлую броню и пылающий молот. Это спокойный idle, а не ходьба или удар.

## Импорт и проверка

Штатный C# `tools/SpriteSheetTool` импортирует четыре компонента в четыре ячейки 64×80. Опора — (32,72), общий масштаб на весь лист, 320 мс/кадр. Для рыцаря content box `1,4,62,68`, инквизитора `0,4,64,68`, крестьянина `8,8,48,64`. Пример после сборки инструмента:

```powershell
dotnet tools/SpriteSheetTool/bin/Debug/net10.0-windows/SpriteSheetTool.dll --components --source docs/art/animations/sources/human-banner-knight.idle.v2.source.png --output content/art/animations/unit.human.banner-knight.idle.v2.png --kind idle --id unit.human.banner-knight.idle.v2 --anchor-mode body --content-box 1,4,62,68 --alpha-cutoff 128 --align-bottom 72 --frame-ms 320 --contact-strip docs/art/animations/previews/unit.human.banner-knight.idle.v2.contact.png
```

Все три импорта находят 4/4 основных фигуры; обрезанных пикселей при размещении нет. Разброс центра ступней по четырём кадрам: рыцарь 1 px, инквизитор 0,5 px, крестьянин 0 px. Субагент проверил соответствие текущим персонажам и читаемость контактных листов. Игровой пример размещения крестьянина: [кадр исследования](../screenshots/human-idle-map-current.png). Для цикла и покадровой проверки — [галерея](animations/preview.html), по умолчанию 0,5×; игровые idle идут на 1× с 320 мс/кадр.

## Финальные промпты

### Рыцарь

Use case: identity-preserve. Game animation sprite sheet EDIT of the provided approved knight. Create ONE wide transparent image with exactly FOUR full-body frames in a single horizontal row, equally spaced separate characters, no text, no ground shadows, no grid. All four are the SAME knight from reference in the SAME right-facing 3/4 resting stance: ivory and black plate armor with gold edges, CLOSED helmet with a very visible sweeping RED PLUME, crimson tabard with gold heraldic lily, LARGE RED SHIELD with GOLD LILY on the SAME arm in all frames, straight sword resting DOWNWARD on the other SAME arm. Preserve his exact proportions, silhouette and limited chunky pixel-art color groups from reference; not photoreal, not tiny polished metallic dithering, not a different armor design. These are four subtle IDLE breathing frames, not walking or attacking. Lock both boots, hips, shield position, head angle and overall scale at identical coordinates within each frame, on a common flat foot baseline. Frame1 relaxed; frame2 slight chest inhalation and cloth/plume tip changes; frame3 relaxed chest and slight cloth motion; frame4 same as1 with tiny plume tip variation. No leg shifts, no foot lift, no body bobbing, no weapon swapping, no silhouette teleporting. Leave generous transparent gaps between frames so every knight is a single separate connected sprite including sword/shield, all extremities fully inside image. Use broad clean pixel clusters comparable to a 70-90px tall classic fantasy strategy sprite. Deliver actual transparent background.

### Инквизитор

Use case: identity-preserve. Create a FOUR-FRAME IDLE animation sprite sheet from this EXACT approved fantasy inquisitor image, ONE wide image, FOUR equally spaced separate full figures in ONE horizontal row, actual transparent background, no labels, no grid, no floor shadows. Preserve SAME identity in ALL frames: CLEAN SHAVEN pale angular face, LONG BLACK HAIR, heavy BLACK AND GOLD plate armor and broad ornate shoulders, crimson cloak, IVORY long tabard with RED heraldic cross, LARGE BLACK/GOLD FLAMING WAR HAMMER held in SAME hand as reference, other hand lowered. Right-facing three-quarter stance same as reference. Match the reference chunky restrained pixel-art, broad solid color clusters, sharp outlines, limited palette; no photorealism, no extra dithering, no redesign, no beard. Idle only: four very subtle breathing/cloth/flame variations. BOTH BOOTS and hips absolutely planted at same relative coordinates, same full-body scale, same head position, shoulders at most one small pixel difference at game scale. Frame1 relaxed, frame2 slight breathing+flame change, frame3 relaxed+cloth tip change, frame4 near frame1 to loop cleanly. No walking, no raised arm attack, no weapon swapping, no shrinking. Keep hammer fully connected via arm/handle as one primary sprite. Leave generous transparent margin outside and between all four characters, no cropped flame or cape. Characters should remain legible when reduced to roughly75px tall.

### Крестьянин

Use case: identity-preserve. Produce ONE transparent pixel-art sprite sheet with exactly FOUR separate full-body IDLE frames in one horizontal row of equally spaced characters, copied faithfully from the supplied approved peasant. Same brown soft cap, angular clean side-facing face, ochre/mustard tunic, white rolled cuffs, small metal shoulder pad, leather belt/pouch, grey trousers, large brown leather boots, and THREE-TINED PITCHFORK held diagonally in both hands in SAME pose/direction as reference. NO axe, no sword, no new clothing, no realistic shading, no text/grid/floor/shadow. Match reference sharp outlined chunky pixel color clusters; designed to remain readable as a60px tall strategy unit. This is a calm breathing idle, not a walk: all four frames keep BOOTS, legs, hips and head planted in identical positions relative to their own equal cell, same proportions/scale, no bouncing. Frame1 reference relaxed; frame2 tiny chest/forearm breathing change; frame3 nearrelaxed slight fabric change; frame4 returns toward1. Pitchfork and hands remain connected and stable, only minimal wrist adjustment. Give a VERY generous outer transparent margin and blank gaps between figures, all pitchfork tips, boots and pouch fully inside canvas. Keep 15% total outer margin on each end if necessary; do not fill the full width with sprites.
