# Инквизитор: поза священного огня

Создано встроенным ImageGen по текущим `unit.human.inquisitor.png` и `unit.human.inquisitor.attack.png`. Исходные утверждённые спрайты сохранены.

Ресурс: `content/art/unit.human.inquisitor.cast.png`. Используется только для режима священного огня; молот сохраняет свою атакующую позу. Это одна поза внутри короткой анимации, а не новый полный покадровый атлас.

## Итоговое задание генерации

Отредактировать текущего инквизитора, сохраняя лицо, длинные тёмные волосы, тяжёлые наплечники, чёрно-золотую броню, багровый плащ и светлую гербовую накидку. Полнофигурный персонаж смотрит вправо: свободная открытая рука протянута для священного огня с небольшим золотистым свечением, молот опущен в другой руке. Сохранить пропорции, палитру и чёткие пиксельные группы исходника; не менять костюм и не добавлять большой снаряд. Обе ступни на одной опорной линии, всё оружие и конечности внутри кадра, прозрачный фон.

## Проверка

Сравнение с текущими позами и просмотр внутри игры при размере 88×100 логических пикселей. Визуальный ревьювер подтвердил соответствие костюма и палитры. Пример игрового кадра: `docs/screenshots/inquisitor-holy-fire-current.png`.

Момент выпуска снаряда общий с кадром отпускания тетивы лучника: 0,2 с после начала действия. Атласы флоры используют один масштаб и одну опорную точку на весь клип, откалиброванные по фактически нарисованному спрайту покоя.
