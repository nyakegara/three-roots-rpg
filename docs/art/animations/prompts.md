# Задания для выбранных источников

Режим: встроенный `image_gen`, прозрачный фон; без CLI/API. Это зафиксированные задания и ограничения для воспроизведения художественного направления, а не обещание побитового повторения генерации. Побитово воспроизводится экспорт из архивных PNG; их SHA-256 записаны в sidecar JSON.

Общее задание (stylized-concept, игровые sprite sheets): сохранить личность и силуэт утверждённого одиночного спрайта из `content/art`. Сдержанная фэнтезийная пиксельная графика, ограниченная палитра, чёткий тёмный контур, цельные фигуры одного масштаба на одинаковой линии земли. Без подписей, фона, подставок, реалистичной фактуры, мягкого свечения и гача-пропорций. Последовательные фазы настоящего действия; свободные поля между фигурами. Для каждой генерации использовался соответствующий существующий спрайт как визуальная ссылка.

## Исправление походки после просмотра пользователем

Первый набор ходьбы отклонён: одна нога постоянно оставалась впереди. Изменение корпуса и плаща ошибочно приняли за достаточное движение. Новые задания требуют шесть фаз: контакт левой ноги → перенос веса → прохождение правой → контакт правой → перенос веса → прохождение левой. Кадры 0 и 3 должны иметь противоположную ведущую ногу. Светлее ближняя нога, темнее дальняя; явно менять направление бёдер, коленей и стоп, не просто перекрашивать прежнюю позу. Корпус держать устойчивым, посох — в той же руке, сохранять одежду и пиксельную стилизацию. Вторая половина нескольких циклов дополнительно исправлялась отдельным редактированием ног.

Новые выбранные архивы: `hero.walk.north.source.png` — N/NE/E (6×3), `hero.walk.se.source.png` — SE (6×1), `hero.walk.south.source.png` — S/SW/W/NW (6×4). Использован встроенный `image_gen`; экспорт выполняется C#-инструментом. Проба с укороченным плащом и открытыми бёдрами отклонена из-за изменения костюма и неверного NW-ракурса.

## Текущий упрощённый вариант

По прямому требованию пользователя оставлены только два кадра на направление: противоположные фазы из столбцов 0 и 3 этих же источников. Новая генерация для этого изменения не выполнялась. Промежуточные фазы исключены, покой заменён одним неизменяемым кадром из SE. Исходные листы остаются архивом; игровой PNG упакован в два столбца.

Последующая правка пользователя: в шести направлениях, кроме N/S, добавлены две промежуточные позы из столбцов 1 и 4. Для покоя замерший кадр шага отклонён и заменён исходным одиночным спрайтом `content/art/hero.flora.png`, сохранённым как `hero.idle.source.png`. Новая генерация не выполнялась. Текущий игровой лист — четыре столбца с разной длиной клипов: N/S по два кадра, остальные по четыре, покой один.
