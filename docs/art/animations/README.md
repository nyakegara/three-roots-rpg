# Анимации флоры — набор для проверки

Откройте `preview.html` двойным щелчком: PNG и разметка встроены в HTML, сервер и интернет не нужны. Пауза, шаг вперёд/назад, скорость и четыре фона помогают проверить силуэт, прозрачность и стык последнего кадра с первым. Красная отметка обозначает опору. Ссылки на исходники и контактные листы работают рядом с остальными файлами репозитория.

Это подготовленные ресурсы. MonoGame пока использует прежние одиночные спрайты; подключение проигрывателя анимаций будет отдельным изменением после просмотра графики.

## Формат

Все игровые PNG находятся в `content/art/animations`. Размер клетки **64×80**, опора **(32,72)**, прозрачность только 0/255. Просмотр — в масштабе 2× без сглаживания. Нумерация кадров начинается с нуля, слева направо, затем сверху вниз. JSON рядом с PNG содержит размеры, индексы, длительность кадров, признак цикла и момент применения действия.

| Лист | Разметка | Действия |
|---|---|---|
| hero.flora.walk | 6×9, 384×720 | N, NE, E, SE, S, SW, W, NW, покой SE; по 6 кадров |
| unit.flora.thorn-guard.actions | 4×2, 256×160 | Кабачок: удар дубинкой, 8 кадров |
| unit.flora.sprout.actions | 4×4, 256×320 | Ипомея: выстрел и лечение, по 8 кадров |
| unit.flora.ember-bloom.actions | 4×2, 256×160 | Пламенный цветок: выстрел, 8 кадров |
| unit.flora.pod-slinger.actions | 4×2, 256×160 | Орхидея: удар клинком, 8 кадров |
| unit.flora.root-warden.actions | 4×4, 256×320 | Грёзник: выстрел и успешное обращение, по 8 кадров |

Всего 110 кадров и 16 клипов. Герой: 110 мс/кадр. Юниты: 100 мс/кадр; `impactFrame=4` — пятый кадр внутри действия. Атаки и способности разовые, хотя галерея намеренно повторяет их для проверки. Обращение гриба — эффект удачного срабатывания после выстрела, не новая активная способность. Анимаций ходьбы юнитов нет.

## Подготовка и воспроизводимость

Исходники генерации сохранены без изменений в `sources`, карты замены строк — рядом с ними. Для героя использованы три источника: основа, исправленные южные/западные направления и SE с покоем. Для Ипомеи лечение заменено отдельным листом, чтобы посох оставался во всех кадрах. Остальные юниты используют по одному источнику.

Изображения распаковываются по связным непрозрачным компонентам: исходная генерация не соблюдала идеальную сетку. C#-инструмент собирает цельные фигуры с их эффектами, применяет единый масштаб для каждого исходника и привязывает тело к линии опоры. Цвета берутся из исходника без фильтрации; альфа ниже 128 отсекается. Размер каждой позы отдельно не подгоняется. Для нового лечения Ипомеи явно задан общий масштаб 0.0959, согласованный с атакой.

Из корня репозитория в PowerShell 7:

```powershell
pwsh -File tools/SpriteSheetTool/Export-All.ps1
pwsh -File tools/SpriteSheetTool/Build-Preview.ps1
```

Первый скрипт пересобирает PNG, JSON и контактные листы из архивных источников. Второй обновляет переносимый просмотр. `index.html` — та же галерея с загрузкой файлов через HTTP для разработки. Подробности экспортёра и проверки путей: `tools/SpriteSheetTool/README.md`.

Оценивать художественно нужно в первую очередь читаемость шага N/NE (он сдержаннее остальных), форму рук/посоха на поворотах, возврат атак в покой и согласованность масштаба с существующими статичными ресурсами. Автоматические проверки не заменяют эту оценку.
