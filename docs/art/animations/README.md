# Анимации флоры — набор для проверки

Откройте `preview.html` двойным щелчком: PNG и разметка встроены в HTML, сервер и интернет не нужны. Пауза, шаг вперёд/назад, скорость и четыре фона помогают проверить силуэт, прозрачность и стык последнего кадра с первым. Красная отметка обозначает опору. Ссылки на исходники и контактные листы работают рядом с остальными файлами репозитория.

Это подготовленные ресурсы. MonoGame пока использует прежние одиночные спрайты; подключение проигрывателя анимаций будет отдельным изменением после просмотра графики.

## Формат

Все игровые PNG находятся в `content/art/animations`. Размер клетки **64×80**, опора **(32,72)**, прозрачность только 0/255. Просмотр — в масштабе 2× без сглаживания. Нумерация кадров начинается с нуля, слева направо, затем сверху вниз. JSON рядом с PNG содержит размеры, индексы, длительность кадров, признак цикла и момент применения действия.

| Лист | Разметка | Действия |
|---|---|---|
| hero.flora.walk | 2×9, 128×720 | N, NE, E, SE, S, SW, W, NW — по 2 кадра; покой SE — 1 кадр |
| unit.flora.thorn-guard.actions | 4×2, 256×160 | Кабачок: удар дубинкой, 8 кадров |
| unit.flora.sprout.actions | 4×4, 256×320 | Ипомея: выстрел и лечение, по 8 кадров |
| unit.flora.ember-bloom.actions | 4×2, 256×160 | Пламенный цветок: выстрел, 8 кадров |
| unit.flora.pod-slinger.actions | 4×2, 256×160 | Орхидея: удар клинком, 8 кадров |
| unit.flora.root-warden.actions | 4×4, 256×320 | Грёзник: выстрел и успешное обращение, по 8 кадров |

Всего 73 используемых кадра и 16 клипов. У героя 18 ячеек: 16 фаз ходьбы, один покой и один неиспользуемый дубликат покоя для прямоугольной сетки. Герой: 220 мс/кадр; покой содержит ровно один индекс и не анимируется. Юниты: 100 мс/кадр; `impactFrame=4` — пятый кадр внутри действия. Атаки и способности разовые, хотя галерея намеренно повторяет их для проверки. Обращение гриба — эффект удачного срабатывания после выстрела, не новая активная способность. Анимаций ходьбы юнитов нет.

## Подготовка и воспроизводимость

Исходники генерации сохранены без изменений в `sources`, карты замены строк — рядом с ними. Три исходных листа героя оставлены для истории; текущие источники ходьбы: N/NE/E, SE и S/SW/W/NW. По требованию пользователя шестикадровый вариант заменён двумя противоположными фазами: столбцы 0 и 3 исходника. Покой использует только один кадр из текущего SE-источника, поэтому поза, масштаб и местоположение не меняются во времени. Для Ипомеи лечение заменено отдельным листом, чтобы посох оставался во всех кадрах. Остальные юниты используют по одному источнику.

Изображения распаковываются по связным непрозрачным компонентам: исходная генерация не соблюдала идеальную сетку. C#-инструмент собирает цельные фигуры с их эффектами и применяет единый масштаб для каждого исходника. Цвета берутся из исходника без фильтрации; альфа ниже 128 отсекается. Размер каждой позы отдельно не подгоняется. Для нового лечения Ипомеи явно задан общий масштаб 0.0959, согласованный с атакой.

Герой экспортируется с `--anchor-mode cell`: центр исходной ячейки по X и общая линия земли для всей строки по Y. Опора больше не следует за перемещающимися стопами; отдельные кадры не сдвигаются к линии земли. Видимая нижняя граница может быть 71 или 72, логическая опора остаётся (32,72). Высота силуэтов 55–57 пикселей; область размещения героя расширена до 64 пикселей, чтобы широкий шаг не уменьшал всю фигуру. Юниты сохраняют прежний режим `body` и прежние PNG/JSON.

Регрессионный тест `tools/SpriteSheetTool/AnchorModeSelfTest.ps1` проверяет неподвижный корпус при смене положения ног. Отдельный тест двухкадрового режима проверяет выбор именно столбцов 0/3, один индекс покоя и отсутствие изменения привязки после удаления промежуточных кадров. Это проверки экспортёра, а не доказательство качества нарисованной походки: две позы оцениваем отдельно по стопам и коленям.

Из корня репозитория в PowerShell 7:

```powershell
pwsh -File tools/SpriteSheetTool/Export-All.ps1
pwsh -File tools/SpriteSheetTool/Build-Preview.ps1
```

Для обновления только героя используйте `Export-All.ps1 -HeroOnly`: остальные пять атласов остаются без записи, но их пиксели также проверяются.

Первый скрипт пересобирает PNG, JSON и контактные листы из архивных источников. Второй обновляет переносимый просмотр. `index.html` — та же галерея с загрузкой файлов через HTTP для разработки. Подробности экспортёра и проверки путей: `tools/SpriteSheetTool/README.md`.

Оценивать художественно нужно смену ведущей ноги между двумя кадрами и положение корпуса. Виды N/NE/NW сложнее оценивать: плащ частично скрывает ноги. Изменения плаща сами по себе не считаются шагом. Также проверяем форму рук/посоха на поворотах и возврат атак в покой. Автоматические проверки не заменяют эту оценку.
