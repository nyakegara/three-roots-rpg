# Главные герои кампаний

Лиара остаётся масштабным и стилистическим эталоном. Эдрик (люди) и Морвен (нежить) имеют собственные пиксельные модели и портреты, а не изображения рыцаря и веталы. Новые исходники в `sources/` выполнены с крупными кластерами цвета и упрощённой фактурой спрайта Лиары.

`preview.html` показывает три игровых атласа рядом, все восемь направлений и покой. Начальная скорость 0,5×. Контактные листы `hero.human.contact.png` и `hero.undead.contact.png` позволяют проверить каждый кадр без запуска игры.

Атласы: 4 столбца × 9 строк, ячейка 64×80. N/S используют по два кадра; остальные направления — по четыре (`контакт → перенос → другой контакт → перенос`). Покой — отдельный неподвижный кадр из нейтральной позы. Левые направления зеркалят соответствующие правые виды. Сборка из исходников:

```powershell
dotnet run --project tools/HeroSpriteBuilder -- "$PWD"
```

Из-за широких плащей шаг на северо-западных ракурсах читается слабее, чем сбоку. При будущем проходе анимаций в игре проверять прежде всего смену стоп и отсутствие смещения корпуса.
