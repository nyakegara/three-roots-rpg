# Анимации нежити: предварительный набор

Листы для пяти утверждённых персонажей. Утбурд имеет отдельные клипы `attack` и `heal`; остальные — `attack` (у Силат песочное заклинание, у Нахцерера радиальный импульс). Это визуальный прототип для проверки пользователем перед включением в игровой рендерер. Текущий рендерер действий ожидает клетки 64×80; здесь клетки 192×192, чтобы не терять утверждённый масштаб и вид оружия.

Открыть `preview.html` локально; выбрать 0,5×, паузу, отдельный кадр и масштаб 1×/2×. PNG и JSON в этой папке перегенерируются командой из корня проекта:

```
dotnet run --project docs/art/undead-sprites/actions/export -- docs/art/undead-sprites/actions
```

Экспорт берёт реальные alpha-компоненты из `sources/*.png`, один масштаб на весь клип, опору ног в `(80,168)` и точечную выборку без размытия. `edge=0` в JSON означает отсутствие обрезки экспортной клеткой; уже обрезанные границей *исходника* части он не восстанавливает.

Независимое визуальное ревью выявило: исходник Утбурда обрезает кисть в четвёртом кадре атаки и последнем кадре лечения; у Силат и Нахцерера часть крайних лап касается границы исходника; у Веталы переход в широкий выпад меняет видимую постановку ног. Для Асуры перегенерирован лист с небольшим пламенем у рта и лучше разведёнными кистями. Перед подключением клипов в игровой рендерер следует адресно исправить отмеченные переходы и показать повторный предпросмотр.
