# Анимации нежити: предварительный набор

Листы для пяти утверждённых персонажей. Утбурд имеет отдельные клипы `attack` и `heal`; остальные — `attack` (у Силат песочное заклинание, у Нахцерера радиальный импульс). Клипы подключены к игровому рендереру с клетками 192×192, чтобы не терять утверждённый масштаб и вид оружия. Арт всё ещё требует правки отдельных исходных кадров.

Открыть `preview.html` локально; выбрать 0,5×, паузу, отдельный кадр и масштаб 1×/2×. PNG и JSON в этой папке перегенерируются командой из корня проекта:

```
dotnet run --project docs/art/undead-sprites/actions/export -- docs/art/undead-sprites/actions
```

Для отправки без браузера: [`undead-actions-half-speed.gif`](undead-actions-half-speed.gif) показывает все шесть клипов на скорости 0,5× с целочисленным масштабом 2×. Он собирается из тех же атласов командой `python docs/art/undead-sprites/actions/export-preview.py` (нужен Pillow); художественные кадры при этом не меняются.

Игровой кадр со всеми пятью бойцами: [`undead-battle.png`](undead-battle.png). Воспроизвести его можно командой `dotnet run --project src/Game.MonoGame/Game.MonoGame.csproj -- --screenshot-combat-undead <абсолютный-путь-к-PNG>`. Для интерактивного боя служит `--combat-undead`.

Экспорт берёт реальные alpha-компоненты из `sources/*.png`, один масштаб на весь клип, опору ног в `(80,168)` и точечную выборку без размытия. `edge=0` в JSON означает отсутствие обрезки экспортной клеткой; уже обрезанные границей *исходника* части он не восстанавливает.

24 октября атака Асуры заменена: глубокий выпад, поворот корпуса, работа трёх пар рук, малых клинков, волос и ткани. [Отдельный GIF на 0,5×](asura-preta-half-speed.gif), [покадровое сравнение](asura-preta-before-after.png). Генерация — встроенный Imagegen с прежним листом и утверждённым спрайтом как референсами; [задание](asura-preta-prompt.md). Упаковка сохраняет один масштаб тела и опору ног, не привязанную к кончику меча; игровая калибровка reference (18,65,119,103) не даёт высокому замаху уменьшать персонажа. Все четыре экспортных кадра без обрезки (edge=0). Независимое ревью принято без блокеров: динамика читается в игровом масштабе, палитра совпадает, вертикального скачка стоп нет. Ограничения: часть шести рук перекрывается на кульминации; четыре фазы сохраняют рубленый ритм.

Оставшиеся замечания к другим юнитам: исходник Утбурда обрезает кисть в четвёртом кадре атаки и последнем кадре лечения; у Силат и Нахцерера часть крайних лап касается границы исходника; у Веталы переход в широкий выпад меняет видимую постановку ног. Их надо адресно исправить в следующем арт-проходе.
