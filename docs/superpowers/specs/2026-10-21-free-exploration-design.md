# Свободное исследование острова

Одобренный пользователем результат: клик задаёт точную точку внутри красных областей присланной разметки. Зелёные островки исключаются. Герой обходит препятствия, двигается плавно и не привязан к центрам гексов. Первый клик показывает маршрут, повторный подтверждает его.

Навигация хранится в JSON карты: система координат исходного рисунка 1862×845, проходимые полигоны, полигоны препятствий, временные препятствия с идентификатором сюжетного открытия, старт и позиции интерактивных точек. Из полигонов строится невидимая сетка с шагом 8 пикселей рисунка. A* строит путь, проверка видимости сглаживает его, конечная точка остаётся точной. Радиус основания героя учитывается на границах.

Бой сохраняет гексы. Старые координаты точек кампании служат стабильными идентификаторами для существующих правил квестов, найма и боёв. В исследовании взаимодействие происходит после прибытия к точке. Север открывается после одной из крестьянских битв, застава и западный берег сохраняют сюжетный порядок.

Сохранение дополнительно хранит координаты героя на рисунке. Поле необязательное: старый сейв восстанавливается у соответствующего ориентира и сохраняет прогресс. Новая позиция проверяется на доступность с учётом сохранённых сюжетных открытий.

Проверка: границы и отверстия, запрет срезать углы, точная конечная позиция, движение по времени, недоступные области, открытие северного и горного проходов, достижимость всех сюжетных точек, сохранение и восстановление. Кадры исследования и обзор с контурами проходимости предоставляются для визуального ревью.

Отдельно проверяется масштабирование Windows: пользовательский кадр 1920×1080 получен из игры с буфером 1280×720. DPI-awareness должен исключить размытие всего окна при системном масштабе 150%. Сам по себе апскейл не превращает живописную картинку в пиксельную графику.
