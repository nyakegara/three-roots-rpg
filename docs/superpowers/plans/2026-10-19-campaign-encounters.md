# Связь исследования и боя

**Цель:** пройти из исследования через подтверждение встречи в бой нанятой армией и вернуться с потерями, золотом и опытом.

**Основание:** общий план кампании, подтверждённый пользователем пробный бой и разрешение продолжать автономно. Планировку карты не менять: встреча временно связана с существующим квестовым местом «Железная дорога». Отдельный прототип `--combat` сохраняется.

**Архитектура:** данные `CampaignEncounter` загружаются из необязательного массива encounters JSON. `Campaign` создаёт единственный активный `CampaignBattle` из актуальной нанятой армии; после завершения проверяет принадлежность сессии, применяет исходных выживших и награду один раз. `ExplorationScreen` держит модальные `EncounterScreen` и `BattleScreen`; сама карта и камера сохраняются при возврате. Экран боя получает уже созданное состояние и callback возврата. Дисковое автосохранение — следующий этап, существующий формат не менять.

- [x] Домен и TDD: отказ без армии/на чужой клетке/после победы; реальные характеристики/способности/численность; победа/поражение; награда один раз; чужая/незавершённая/устаревшая сессия; переполнение без частичных изменений; чужие обращённые стеки не нанимаются, выжившие в следующем бою здоровы.
- [x] JSON и TDD: необязательный encounters совместим с остальными кампаниями; ссылки, фракция, числа, дубликаты и лимит 5; одна временная встреча road-patrol на iron-road, 4 ополченца, 2 копейщика, 1 лучник, 60 золота/60 опыта. Карты не редактировать.
- [x] UI: окно подтверждения с армией врага, наградой и запретом боя без своей армии; начало/отмена без клика сквозь окно; боевой итог с возвратом и без повтора ради награды; после возврата актуальные стеки и сообщение на HUD. Escape закрывает окно подтверждения; в незаконченном бою закрывает приложение, после итога возвращает на карту.
- [x] Реальные кадры: встреча с пустой армией/нанятой армией, бой из исследования, итог, возврат после победы. Скриншотный сценарий нанимает по обычным правилам, запускает и разрешает бой через доменные команды; обычная кампания при запуске остаётся без бесплатных войск.
- [x] Полная сборка/тесты, независимое ревью домена/ввода и визуального качества; коммиты и пользовательский контрольный показ нового окна.

**Не включено:** перестановка объектов, новые рисунки карты и врагов, квестовый диалог выбора, навыки, сохранение кампании на диск. Поражение не выдаёт награду и оставляет встречу; можно нанять новую армию из оставшегося запаса. Дальнейшее прохождение и баланс трёх кампаний требуют отдельного этапа.

## Результат проверки

Release: 0 предупреждений, 0 ошибок; 325/325 тестов. Подтверждены обычный запуск с пустой армией, найм с расходом золота и запасов, победа через реальные боевые команды, возврат выживших, награда один раз, запрет повторного боя и недействительных результатов. Независимое code review не нашло блокеров P1/P2; визуальное ревью одобрило все пять кадров. Старые экраны исследования, найма и отдельного боя сняты из актуальной сборки без ошибок. Файлы карт не менялись. Следующая пользовательская проверка — новое окно встречи и возврат на карту; прогресс на диск пока не сохраняется.
