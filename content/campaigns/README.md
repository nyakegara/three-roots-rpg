# Формат мини-кампаний

Файл кампании связывает героя, фракции, карту, доступный найм и задания. `mapFile` задаётся относительно самого файла кампании. Каждый `pointOfInterestId` задания должен совпадать с точкой типа `quest` на карте. Загружаемые войска должны принадлежать фракции игрока и присутствовать в `content/units/units.json`.

Варианты задания задаются своими ID, описанием, изменением золота и изменением репутации. Золото может быть потрачено (отрицательное `goldChange`), а итоговая репутация ограничивается игровым правилом диапазоном от −3 до +3.

`CampaignLoader` возвращает определения и список `ContentError` с путём файла. Он не запускает игру и не меняет состояние героя. `CampaignDefinition.CreateGameState()` создаёт свежего героя и кампанию из загруженных правил.
