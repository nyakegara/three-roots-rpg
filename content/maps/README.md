# Формат карт

Каждая карта исследования хранится в отдельном UTF-8 JSON-файле. Координаты `q` и `r` — осевые координаты гекса. `width` и `height` задают прямоугольные границы допустимых неотрицательных координат; клетка, отсутствующая в `tiles`, считается за пределами карты.

```json
{
  "id": "tutorial",
  "name": "Поля у старого дуба",
  "width": 6,
  "height": 5,
  "start": { "q": 0, "r": 2 },
  "tiles": [
    { "q": 0, "r": 2, "terrain": "grass", "height": 0, "passable": true }
  ],
  "pointsOfInterest": [
    { "id": "old-oak", "type": "quest", "name": "Старый дуб", "q": 0, "r": 2 }
  ]
}
```

Обязательны `id`, `name`, положительные `width` и `height`, стартовая клетка и непустой список `tiles`. У клетки обязательны координаты; `terrain` по умолчанию равен `grass`, `height` — `0`, `passable` — `true`. Высота задаётся неотрицательным целым числом. Старт должен ссылаться на существующую проходимую клетку.

Точки интереса задаются необязательным списком. У каждой должны быть заполнены `id` и `type`; ID должны быть уникальны, а координаты должны указывать на существующую клетку. Несколько точек могут занимать один гекс. Примеры типов: `quest`, `treasure`, `recruitment` и `exit`.
