# Каталог войск

`units.json` содержит определения всех существ. У каждого существа есть стабильный `id`, идентификатор фракции, имя, параметры боя, стоимость найма и заменяемый `artKey`. Ключ изображения не загружается доменной логикой: отрисовка находит PNG через каталог ресурсов.

Параметры `hitPoints`, `damage`, `speed`, `movement`, `range` и `recruitmentCost` должны быть положительными целыми числами. `isRanged` задаёт дальнобойную атаку. Идентификаторы уникальны, например `flora.sprout`.

Сейчас каталог содержит 17 типов войск трёх фракций. Пять ролей флоры и пять ролей людей используются в первой кампании; дополнительные определения и нежить служат основой следующих кампаний. Числовые значения ещё проходят балансную проверку.
