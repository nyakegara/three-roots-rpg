# Каталог войск

`units.json` содержит определения всех существ. У каждого существа есть стабильный `id`, идентификатор фракции, имя, параметры боя, стоимость найма и заменяемый `artKey`. Ключ изображения не загружается доменной логикой: он остаётся строкой для будущего каталога ресурсов.

Параметры `hitPoints`, `damage`, `speed`, `movement`, `range` и `recruitmentCost` должны быть положительными целыми числами. `isRanged` задаёт дальнобойную атаку. Идентификаторы уникальны, например `flora.sprout`.

Сейчас каталог содержит по пять отрядов флоры, людей и оригинальных существ нежити. Их числовые значения — начальные балансные ориентиры, а не финальный баланс.
