# Заменяемая графика прототипа

Клади свои PNG в эту папку, сохраняя следующие имена:

| Ключ / файл | Назначение | Область отрисовки |
| --- | --- | --- |
| `hero.flora.png` | Герой-заглушка на карте исследования | 74×96 пикселей |
| `unit.human.guard.png` | Занятая клетка с противником-заглушкой | 48×64 пикселя |
| `terrain.rock.png` | Непроходимый камень | 56×48 пикселей |
| `portrait.flora.png` | Портрет выбранного героя в нижней панели | 84×94 пикселя |
| `exploration.ground.png` | Фоновая иллюстрация карты исследования целиком | Масштабируется под карту кампании |
| `terrain.old-oak.png` | Квестовый старый дуб | 160×150 пикселей |
| `poi.treasure.png` | Тайник на карте исследования | 50×43 пикселя |

Рекомендуются прозрачный фон и указанные размеры. Изображения другого размера масштабируются в область отрисовки с фильтром PointClamp. Нижний край персонажа располагается у основания клетки.

После замены файла достаточно повторно собрать и запустить проект. MSBuild копирует эти файлы в `Content/art` рядом с приложением; `AssetCatalog` загружает их по постоянным ключам. Если изображения нет, остаётся процедурная заглушка. Боевые правила и поиск пути от рисунков не зависят.

Фоновая иллюстрация подстраивается под размеры карты и перемещается вместе с камерой. Герой, деревья, точки интереса и портрет остаются отдельными изображениями: их можно менять независимо от фона и игровых правил. Сейчас все изображения служат заменяемыми заглушками; окончательная графика будет определена вместе с кампаниями.
