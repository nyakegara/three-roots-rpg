# Заменяемая графика прототипа

Клади свои PNG в эту папку, сохраняя следующие имена:

| Ключ / файл | Назначение | Область отрисовки |
| --- | --- | --- |
| `hero.flora.png` | Герой-заглушка на карте исследования | 74×96 пикселей |
| `unit.human.guard.png` | Занятая клетка с противником-заглушкой | 48×64 пикселя |
| `terrain.rock.png` | Непроходимый камень | 56×48 пикселей |
| `portrait.flora.png` | Портрет выбранного героя в нижней панели | 84×94 пикселя |
| `exploration.ground.png` | Фоновая иллюстрация карты исследования целиком | Масштабируется под карту кампании |
| `terrain.old-oak.png` | Старый дуб — точка квеста «Голос родника» | PNG 80×75, выводится 160×150 |
| `poi.treasure.png` | Тайник на карте исследования | 50×43 пикселя |
| `poi.flora.root-greenhouse.png` | Точка найма «Корневая оранжерея» на карте | PNG 48×48, выводится 96×96 |
| `poi.flora.sunny-clearing.png` | Точка найма «Поляна жарких цветов» на карте | PNG 48×48, выводится 96×96 |
| `poi.flora.spore-circle.png` | Точка найма «Споровый круг» на карте | PNG 48×48, выводится 96×96 |
| `battlefield.forest.day.png` | Задний план боя при дневном свете | PNG 640×305, выводится 1280×610 |
| `battlefield.forest.night.png` | Задний план боя при лунном свете | PNG 640×305, выводится 1280×610 |

Рекомендуются прозрачный фон и указанные размеры. Три постройки найма хранятся на нативном холсте 48×48 и отображаются целым масштабом 2× (96×96 экранных пикселей); дуб — на холсте 80×75 с масштабом 2× (160×150). Для сохранения чётких кластеров точек будущие объекты карты следует готовить в нативном размере и выводить целым масштабом с PointClamp. Нижний край персонажа располагается у основания клетки.

После замены файла достаточно повторно собрать и запустить проект. MSBuild копирует эти файлы в `Content/art` рядом с приложением; `AssetCatalog` загружает их по постоянным ключам. Если изображения нет, остаётся процедурная заглушка. Боевые правила и поиск пути от рисунков не зависят.

Боевые задние планы хранятся парой на непрозрачных холстах 640×305 и растягиваются целым масштабом 2× на область 1280×610. При переключении N изображения плавно смешиваются. Если доступен только один фон, он отображается целиком; если нет обоих, используется процедурная поляна.

Фоновая иллюстрация подстраивается под размеры карты и перемещается вместе с камерой. Герой, деревья, точки интереса и портрет остаются отдельными изображениями: их можно менять независимо от фона и игровых правил. Три постройки найма выбираются по `RecruitmentSiteId`; для неизвестных точек или отсутствующих файлов отображается процедурная отметка-заглушка.
